# 枢 · 生活工作台 (Shu Life Workbench)

> 一个把「生活」当系统来设计的集成式个人工作台。数据在你手里，界面克制而温暖。

集成「今日生活指数、记账理财、减脂健身、生活习惯、日程统筹、待办」六大模块的单页应用。单文件起步，逐步演进为 PWA + 云端同步 + 桌面应用。

## 功能一览

| 模块 | 能力 |
|------|------|
| 今日生活指数 | 睡眠 / 运动 / 收支 / 日程 / 待办 / 心情 六维聚合，生成当日生活指数 |
| 记账理财 | 收支记录、月度统计、投资分配视图 |
| 减脂健身 | 体重体脂趋势、日锻炼计划、卡路里摄入计算 |
| 生活习惯 | 睡眠、美容、塑形 / 拉伸 / 面部按摩打卡 |
| 日程统筹 | 按日 / 周 / 月视图的日程管理 |
| 待办 | 优先级待办清单（P0–P4） |
| AI 助手（预留） | 大模型 API 会话入口，可与上述数据打通 |

## 技术架构

```
┌─────────────────────────────────────────┐
│  前端：原生 HTML + CSS + JS（零框架）     │
│  index.html  ← 全部组件、图标、样式内联   │
├─────────────────────────────────────────┤
│  数据层：StorageAdapter（抽象接口）       │
│  ├─ LocalAdapter  → localStorage        │
│  └─ CloudAdapter  → Supabase（开发中）   │
├─────────────────────────────────────────┤
│  PWA：manifest.json + service worker     │
│  安装到主屏 · 离线可用 · 手机/电脑同源    │
└─────────────────────────────────────────┘
```

- **数据主权**：默认全部数据仅存于你的浏览器 localStorage，JSON 可导出 / 不限条数导入，满 20 条提醒备份；存储失败与数据损坏有明确提示与恢复路径。
- **零依赖**：不依赖任何外部 CDN / 框架 / 字体，离线可用。
- **隐私**：云端同步为可选项，凭据只存本地配置，绝不入库。

## 快速开始

```bash
# 方式一：直接双击 index.html 用浏览器打开
# 方式二：本地服务器（PWA / Service Worker 需要）
python -m http.server 8765
# 浏览器访问 http://localhost:8765
```
