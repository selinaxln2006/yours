# Yours · PRD v0.3

> 2026-10 · v0.2 已上线；v0.3 = 会话体验 + 目标周循环（见 §5.5–5.7）
> 这份文档回答「做什么、为谁、为什么、不做什么」。架构与进度见 [ROADMAP.md](ROADMAP.md)。

## 1. 一句话

**把目标落到每天，并在你最容易掉线的时候拉你一把。**

> v0.3 修正：到家只是"掉线点"的一个例子。核心是一个了解你的助手——知道你的目标和习惯，陪你每周复盘、调整计划，在你承诺过的事上温和地约束你。

本地运行的个人 agent：你和它聊目标，它帮你拆成这周和每天的参考计划；你挑今天真要做的；到了你容易躺平的时刻（比如一到家），它按你定的规则提醒你。

## 2. 为谁

**第一版只为一个人：作者自己**（学生，课多事杂、作息不规律，讨厌被 App 管，但也知道自己需要一点外力）。

不是"所有人的效率工具"。先在一个真实用户身上把循环跑通，再谈推广。

## 3. 要解决的三个具体问题

| # | 场景 | 现在的痛 |
|---|------|---------|
| P1 | 有目标，但拆不到日常 | "这学期把量化面试准备好"→ 不知道今天该干嘛，于是今天什么都没干 |
| P2 | 计划很分散，执行和计划对不上 | 计划写在脑子里、备忘录、日历三处；晚上回看才发现一件没做，也不知道为什么 |
| P3 | 到家就躺，一躺五小时 | 不是不想做，是缺一个"现在、就这一件"的推力；事后又自责 |

## 4. 核心循环

```
聊目标 ──▶ 拆成参考计划（周 → 日，标为「建议」）
              │
              ▼
        你挑今天要做的（点「今天做」→「承诺」）
              │
              ▼
   到了关键时刻（到家）还有承诺没完成 ──▶ 按你的规则提醒
              │
              ▼
        做完勾掉 / 没做完一键挪到明天 / 今天算了
```

两个关键设计：

1. **建议 ≠ 承诺。** AI 拆出来的计划只是参考，不提醒、不计入"没完成"。只有你自己点过「今天做」的事才算数。计划可以多，承诺要少。
2. **提醒是你定的规则，不是它的判断。** 什么时候算"到家"、提醒几次、多硬、几点后闭嘴，都由你设置；默认关闭。

## 5. 功能（v0.2 范围）

### 5.1 目标 → 计划
- 在目标面板点「和 Yours 拆解」→ 进入对话，agent 读现状后给出本周 / 每天的参考待办
- 写入时标为 **建议**，带目标关联（`goalId`）；重新拆解会替换该目标下尚未承诺的旧建议
- 一次写入一整份计划（不逐条弹确认卡）：建议本身不产生任何外部影响

### 5.2 今天
- **今天要做**：已承诺、今天到期或已逾期、未完成的事；可勾选完成
- **建议**：今天的参考待办，点「今天做」变成承诺，点 × 不要
- **没做完的挪到明天**：一键把逾期 / 今天未完成的承诺改到明天
- 待办可以标「🏠 到家后提醒」

### 5.3 到家提醒
- **触发**：
  - 手动：点「我到家了」（今天面板、⌘K）
  - 自动（可选）：iPhone 快捷指令「到达家」个人自动化 → 请求本机 `POST /api/home`
- **提醒什么**：今天还没完成的承诺（可设为只提醒标了「到家后」的）
- **力度**（全局默认，后续可按任务覆盖）：
  - 温和：提醒一次
  - 跟进：每隔 N 分钟一次，最多 M 次，直到完成 / 点「今天算了」
  - 强：同跟进，推送用最高优先级（ntfy urgent / Bark 时效性通知）
- **安静时段**：如 00:30–08:00 不发
- **渠道**：
  - 网页内（console 开着时弹卡片 + 系统通知）
  - ntfy（手机装 ntfy App 订阅一个私密频道）
  - Bark（iOS 推送 App，一个 key）
  - 自定义 webhook（POST JSON，可接 Telegram / Slack / 自动化平台）

### 5.5 目标周循环（v0.3）
- 建议挂在对应目标下面（目标卡里显示建议与已加入的事），点 + 加入
- 拆解是讨论式的：先问进度、这周有多少时间、卡在哪，再给建议；建议随每周进度调整
- **周复盘**：每周第一次打开（默认周一，可改）时，对话里出现一张卡：上周承诺完成度、每个目标的上周进度与本周已有建议；一键让 Yours 点评上周并按目标给本周建议

### 5.6 会话体验（v0.3）
- 人设：了解你的朋友兼教练——直接、具体、不说教；约束是你授权的，"拉一把"不是批评；不管没请它管的事
- 每轮自动注入现状：时间、今天的承诺与建议、目标进度、上周完成率、已约的回访
- 记忆：对话里主动记；每聊 3 轮后台整理一次"值得长期记住的事"；「它眼中的你」页面可看、可改、可删、可手动添加
- 回访：你说"先躺会儿 / 等下再做 / 我在路上"，它约一个回访（如 30 分钟后），到点在网页和手机渠道问你一句
- 确认卡可直接改参数（热量、食物名、日期…）再允许

### 5.7 约束的触发点（v0.3）
- 到家：手动 / 快捷指令 / 对话里说"到家了"；**默认先缓 15 分钟再问**
- 晚间检查：到设定时间还有没完成的承诺，问一句"现在做一件，还是挪到明天"
- 对话里约的回访（见 5.6）

### 5.4 不做（v0.2）
- 自动发邮件、下单、付款
- 多人 / 社交
- 情感陪伴式闲聊
- 主动"猜"你的状态（不读手机传感器、不分析屏幕时间）

## 7. 安全与边界

- 所有数据在本机 `paa/data/`；推送内容只发到你自己配置的渠道
- 推送正文只含待办标题，不含其他生活数据
- AI 写入「建议」免确认；写入「承诺」、删除、执行命令等仍走确认卡
- 提醒默认关闭；关掉开关即刻停止，不留后台任务

| 指标 | 目标 |

## 9. 开放问题

- 提醒文案的语气：温和的推力 vs 带点幽默的激将？先用中性文案，自用两周后再定
- 「今天算了」之后要不要第二天早上提一句昨天没做的？（倾向：不提，交给「挪到明天」）
- 建议计划多久过期？（倾向：过了日期自动隐藏，不删除）
