# 到家提醒：怎么设置

设计见 [PRD.md](PRD.md) §5.3。一句话：**你说"我到家了"，如果今天还有承诺过的事没做完，Yours 按你定的规则提醒你。** 默认关闭。

## 1. 打开提醒

控制台 → 设置 → **到家提醒**：

| 项 | 说明 |
|---|---|
| 开关 | 关掉即刻停止 |
| 力度 | 温和：只提醒一次 · 跟进：每隔 N 分钟一次，最多 M 次 · 强：同跟进，推送用最高优先级 |
| 提醒哪些 | 今天所有没做完的承诺，或只提醒标了 ⌂ 的（待办面板里点 ⌂ 标记） |
| 到家缓冲 | 到家后先等几分钟再问（默认 15，0 = 立刻） |
| 晚间检查 | 到这个时间还有没做完的承诺就问一句（留空 = 不检查） |
| 安静时段 | 这段时间不发任何提醒（起止相同 = 不设） |

**对话里的回访**：你在对话里说"先躺会儿""等下再做"，Yours 会约一个回访，到点问你一句。回访是你自己同意的，所以不受"开关"限制，只受安静时段限制。

只提醒「承诺」：AI 拆出来的「建议」不会提醒，你点过「今天做」的才算。点提醒卡上的「今天算了」，当天不再提醒。

## 2. 推送到手机（选一个）

网页开着时一定会弹卡片（允许浏览器通知后，切到别的标签页也会有系统通知）。要在锁屏收到，选一个渠道：

### ntfy（推荐，最快）
1. 手机装 **ntfy** App（iOS / Android 都有，免费，不用注册）
2. App 里订阅一个**只有你知道的频道名**，比如 `yours-` 加一串随机字母（频道名就是密码，别用常见词）
3. 设置里渠道选 ntfy，地址填 `https://ntfy.sh/你的频道名`，保存，点「发一条测试」

> ntfy.sh 是公共服务器：知道频道名的人都能看到推送内容。推送里只有待办标题，但如果介意，可以自建 ntfy 服务器，地址换成自己的即可。

### Bark（iOS）
1. 装 **Bark** App，复制首页的地址（形如 `https://api.day.app/xxxxxxxx`）
2. 渠道选 Bark，粘贴地址，保存，测试

「强」档会用 Bark 的紧急通知（无视静音），慎用。

### 自定义 webhook
POST JSON 到你给的地址：

```json
{ "source": "yours", "kind": "nudge", "title": "到家了", "body": "…", "urgent": false, "todos": ["交作业", "背单词"] }
```

可以接 Telegram bot、Slack、n8n / Make 等任何自动化平台。

## 3. 自动判断"到家"（可选，iPhone）

不想每次手动点「我到家了」：

1. 前提：手机能访问这台电脑上的 Yours（同一局域网开了 LAN 模式，或者用 Tailscale）
2. iPhone「快捷指令」→ 自动化 → 新建个人自动化 → **到达** → 选你家的位置 → 立即运行
3. 动作：**获取 URL 内容**
   - URL：`http://<电脑地址>:18765/api/home`
   - 方法：POST
   - 如果开了局域网访问令牌（`paa/data/lan.json`），在「头部」加 `x-access-token`，值是令牌
4. 回到家试一次：控制台的「今天」应该弹出提醒卡

令牌等同于这台电脑上 Yours 的钥匙，只放在你自己的快捷指令里。

## 4. 排查

- **点了测试，手机没收到**：先看设置页的提示（"推送失败：HTTP xxx" 说明地址不对）；ntfy 确认 App 订阅的频道名和地址最后一段完全一致
- **到家了没提醒**：看「今天」里有没有未完成的**承诺**（建议不算）；看是否在安静时段；是否今天点过「今天算了」
- **提醒太多**：力度改温和，或把间隔调长、次数调少
